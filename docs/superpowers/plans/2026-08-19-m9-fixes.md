# M9 Fixes — Release Signing + Cursor Adapter Implementation Plan

> **Status: shipped (2026-09-17).** Task 1 went out in `v0.2.1`. Tasks 2 and 3
> are on `main`: the six commits `b227fe6`…`c423594` (ACP handshake timeout,
> `cursor-print` T3 adapter, plus their fix rounds) were cherry-picked off the
> now-deleted `worktree-m9-app` branch, carrying only `src/adapters/*` and their
> tests. Verified against the real `cursor-agent` 2026.09.10 — the
> `cursor-print` round-trip renders streamed deltas and the ACP path fails fast
> with a clear message after 15s instead of hanging — and end-to-end through the
> daemon (`session.new` → tier T3 → `session.attach` → real answer → clean
> kill). Kept as the record of what those commits are for.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make released binaries runnable on macOS (fix unsigned-artifact SIGKILL) and make the `cursor` adapter either work or fail loudly and helpfully (cursor-agent dropped ACP).

**Architecture:** Two independent fixes. (1) The release pipeline builds darwin artifacts with `--target=bun-darwin-arm64` under bun 1.3.12, whose cross-compile path produces binaries with no code signature — macOS arm64 then SIGKILLs them (exit 137). Fix: pin bun 1.3.14 (verified to emit linker-signed binaries) and adhoc-sign darwin artifacts in CI. (2) `AcpAdapter` spawns `cursor-agent agent acp`, but current cursor-agent builds (2026.08.04+) removed the ACP protocol entirely — `agent acp` is now just the interactive CLI with prompt "acp". The handshake `initialize` never resolves, `sessionId` stays undefined, `pendingWrites` queue forever, and the session shows `running` while being dead-silent. Fix: 15s handshake timeout that kills the process and surfaces a clear error; plus a new T3 adapter `cursor-print` that drives the still-supported `--print --output-format stream-json` mode.

**Tech Stack:** Bun, GitHub Actions, `@agentclientprotocol/sdk`, `cursor-agent` CLI.

## Global Constraints

- CI pins Bun to a version that produces signed darwin binaries: `1.3.14` (verified locally — `bun run scripts/build.ts --target=darwin-arm64` with 1.3.14 yields `flags=0x20002(adhoc,linker-signed)`; 1.3.12 does not).
- All darwin release artifacts MUST be at least adhoc-signed before upload (`codesign -dv` must report a CodeDirectory, not "code object is not signed at all").
- Adapter kinds stay explicit: `claude` (T2), `cursor` (T1, ACP), `cursor-print` (T3, stream-json). No silent fallback between tiers.
- Errors use `CrossweaveError` with string codes; user-facing text in English.
- No new runtime dependencies.
- Tests: `bun test`, TDD red-green per task.

- [ ] **Step 4: Implement the timeout**

In `src/adapters/acp.ts` (top of file, after the existing imports):

```typescript
export const ACP_HANDSHAKE_TIMEOUT_MS = 15_000;
```

In the `AcpProcess` constructor, replace the `void (async () => { ... })().catch(() => {});` block so it arms a timeout that kills the child on stall:

```typescript
    const handshake: Promise<void> = (async () => {
      await connection.initialize({ protocolVersion: PROTOCOL_VERSION, clientCapabilities: {} });
      const { sessionId } = await connection.newSession({ cwd: opts.cwd, mcpServers: [] });
      this.sessionId = sessionId;
      for (const text of this.pendingWrites.splice(0)) {
        void connection.prompt({ sessionId, prompt: [{ type: 'text', text }] }).catch(() => {});
      }
    })();

    // cursor-agent removed ACP support in 2026.08.x releases — `agent acp` now opens
    // the interactive CLI, so initialize() never resolves and the session would sit
    // `running` forever with every write() queued. Fail loudly instead: kill the
    // child, surface the reason, and exit so the runtime marks the session dead.
    const timeout = setTimeout(() => {
      if (this.sessionId !== undefined) return;
      this.child.kill('SIGKILL');
      fanOut(this.dataListeners, 'crossweave: cursor-agent did not respond to the ACP handshake in 15s. Current cursor-agent builds removed ACP support — use `--agent claude` or `--agent cursor-print`.\n');
      fanOut(this.exitListeners, 1);
    }, ACP_HANDSHAKE_TIMEOUT_MS);

    handshake
      .then(() => clearTimeout(timeout))
      .catch(() => clearTimeout(timeout));
```

- [ ] **Step 5: Implement the adapter**

Create `src/adapters/cursor-print.ts`:

```typescript
import { spawn, type ChildProcess } from 'node:child_process';
import { createInterface } from 'node:readline';
import type { AgentAdapter, AgentProcess, SpawnOptions } from './types.js';
import type { EnforcementTier } from '../db/repositories/session.js';

function fanOut<T>(listeners: ReadonlyArray<(value: T) => void>, value: T): void {
  for (const cb of listeners) {
    try { cb(value); } catch { /* subscriber owns its failure */ }
  }
}

export class CursorPrintAdapter implements AgentAdapter {
  readonly kind = 'cursor-print';
  // T3: no permission interception — the stream-json mode exposes no hook
  // equivalent. Collision Radar still warns via bus messages, but writes are
  // never blocked (see docs/superpowers/specs/2026-08-12-m5a-safe-mode-blocking-design.md).
  readonly enforcementTier: EnforcementTier = 'T3';

  static readonly DEFAULT_ARGS: string[] = [
    '--trust', '--print', '--output-format', 'stream-json', '--stream-partial-output',
  ];

  constructor(
    private readonly command = 'cursor-agent',
    private readonly args: string[] = CursorPrintAdapter.DEFAULT_ARGS,
  ) {}

  spawn(opts: SpawnOptions): AgentProcess {
    return new PrintProcess(this.command, this.args, opts);
  }
}
```

Implement `PrintProcess` (in the same file) with the same shape as `AcpProcess`: `spawn(command, args, { cwd, env })`, `onData`/`onExit` fan-out, `write()` that sends the prompt verbatim through stdin, `resize()` no-op, `kill()` → `child.kill()`. Parse stdout with `createInterface({ input: child.stdout })`, one line at a time: JSON.parse the line; `type: 'text'` → emit the `text` field; other shapes → emit a bracketed line `[cursor: <type>]`; non-JSON lines → emit raw. Forward stderr to `onData` exactly like `AcpProcess` does.
