# crossweave website — implementation plan

> **For agentic workers:** implement task by task, tests first. Steps use checkbox syntax.

**Goal:** A static, dependency-free site for crossweave (home, download, docs, changelog, 404; English, with Vietnamese for home and download), built by one Bun script and deployed to GitHub Pages.

**Architecture:** `website/build.ts` renders pure page functions (content → HTML string) into `website/dist`; markdown goes through `Bun.markdown.render` with our own callbacks; colours come from the cockpit's token modules; release data comes from a committed manifest that an explicit flag refreshes.

**Tech stack:** Bun 1.3.14 (pinned, as `release.yml`), TypeScript strict, `bun test`. No npm dependency of any kind.

**Spec:** `docs/superpowers/specs/2026-10-11-website-design.md` (read it first; this plan does not repeat its rationale).

## Global constraints

- **No dependency.** `website/package.json` has scripts only. No web fonts, no third-party script/image/stylesheet, no JavaScript in the pages, no cookie, no analytics.
- TypeScript `strict` + `noUncheckedIndexedAccess` (root `tsconfig.json`), no `any`, no `!` without a stated reason, no `@ts-ignore`. Comments say WHY only. English copy in code; Vietnamese only in `vi.ts`.
- `main` stays linear and nobody commits to it: work on `feat/website` (exists). One logical change per commit, Conventional Commits.
- Run one gate at a time, outside the sandbox where a test spawns a process or binds a socket, `--max-concurrency=1`. Never two test runs at once (the Stop hook runs a suite in the background). A heredoc containing words such as `.env`/`secret` can be blocked by a hook: write such files with the Write/Edit tools.
- Every claim in the copy is one the repository can back and carries its own qualifier (spec, "Claims discipline"). No third-party product is named except as a launcher name in plain text.
- Escaping contract: **leaf text and attributes are escaped exactly once**, at the leaf (`text` callback, attribute values, copy interpolated into a page). Anything that is already HTML (a markdown result, a page `body`) is typed `Html` (a branded string) and is never escaped again. Heading slugs come from the plain text of the heading.
- Every task ends with the new tests green, `bun run typecheck` clean, and a commit.

## Review focus (failure modes the spec implies that no happy path covers)

1. Hostile markdown (raw `<img onerror>`, `<script>`, `javascript:`/`data:` links, an off-site image, a quote inside a title) must come out inert (Task 2).
2. `<` in a code block must be escaped exactly once, not zero or two times (Task 2).
3. A project-site base path (`/crossweave`) must be applied to every link, asset, canonical, OG, hreflang and sitemap entry, and `404.html` must work from any depth (Task 1, Task 7).
4. A failed, hanging or malformed release refresh must leave the committed manifest untouched; two offline builds must be byte-identical (Task 5, Task 7).
5. README restructured (a heading renamed, a section moved) must fail the build, not silently produce a thinner docs section (Task 6).
6. A Vietnamese page missing a key must fail typecheck, and the two languages must not drift in item counts (Task 4).
7. Light and dark text/background pairs must reach WCAG AA (Task 3).

### Task 2: A markdown renderer that cannot be talked into anything

**Files:** Create `website/src/markdown.ts`, `website/tests/markdown.test.ts`, `website/tests/fixtures/markdown-all.md`.

**Interfaces — Produces:**

```ts
export interface ImageInfo { src: string; width: number; height: number }

  /** Maps an image src to a site image with its size, or null to drop it. Default: drop every image. */
```

Probe results already established on Bun 1.3.14 (do not re-derive): `Bun.markdown.render(source, callbacks)` calls, with children already rendered as the first argument: `heading(children, {level})`, `paragraph`, `text`, `strong`, `emphasis`, `codespan`, `strikethrough`, `code(children, {language})`, `link(children, {href, title})`, `image(children, {src, title})`, `list(children, {ordered, start, depth})`, `listItem(children, {index, depth, ordered})`, `table`, `thead`, `tbody`, `tr`, `th(children, {align})`, `td(children, {align})`, `blockquote`, `hr`, `html`. An element with no callback is rendered as its bare children (a table collapses to text), which is why every one of these gets one. **`text` is the only callback that receives raw text: it escapes (once). `code` and `codespan` receive text that `text` has already escaped, and every container receives already-rendered HTML: none of them escapes its children again.** `html` returns `''` and increments `droppedHtml`. A heading's `children` is rendered inline HTML: its plain text for the slug is that string with tags removed and entities decoded.
