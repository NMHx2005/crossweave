# Full Bilingual Website Implementation Plan

> **For agentic workers:** Execute this plan task by task using TDD. Keep each task green before moving on; run required gates sequentially.

**Goal:** Give every public site page an English and Vietnamese counterpart, including all documentation, release history, navigation and metadata.

**Architecture:** Keep current English documentation and changelog sources, add translated Markdown and typed Vietnamese labels, and build matched routes for both locales. Pass locale-specific release notes through page rendering so changelog content, home-page release teasers, and links remain in the selected language.

**Tech Stack:** Bun, TypeScript, static HTML renderer, Markdown sources, `bun:test`.

**Spec:** `docs/superpowers/specs/2026-10-13-website-full-bilingual-design.md`

## Global Constraints

- The site remains dependency-free and statically generated by `bun website/build.ts`.
- Keep the README, `SECURITY.md`, and `docs/releases/v*.md` as the canonical English sources.
- Preserve exact command names, flags, code fences, paths, environment variables, schema identifiers and product names in translations.
- Translate all currently shipped releases, v0.3.0 through v0.6.0, and fail the build if a locale counterpart is missing.
- Keep tag-level release anchors identical across languages.
- Do not commit to `main`; work on `codex/website-full-i18n`.
- Run repository gates sequentially; full tests use `bun test --max-concurrency=1`.
