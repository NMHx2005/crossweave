# Professional bilingual subpages — known limitations

This milestone gives Download, Documentation and Changelog clearer navigation and hierarchy in both English and Vietnamese, using the existing static build and theme tokens.

- Documentation navigation is generated from the current Markdown headings. There is no full-text search or versioned documentation snapshot.
- The Changelog index links to every release on one static page; it does not filter or paginate releases.
- English and Vietnamese copy is maintained manually. Independent Vietnamese technical proofreading remains open.
- Visual smoke review covered EN/VI Download, Docs and Changelog at desktop and 390px mobile widths in Chrome. Firefox and Safari have not been checked. The local static preview remains available at `http://127.0.0.1:4178/` for further review.
